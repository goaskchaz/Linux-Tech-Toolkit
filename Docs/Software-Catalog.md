- Free software does not guarantee compatibility with every device, PLC, or radio.
- Windows licenses and some manufacturer-specific PLC/radio tools may be proprietary.
- Drive sanitization is media-specific: HDD overwrite and SSD sanitize/secure erase are not interchangeable.
- Package availability and installation commands vary by distribution and release.
- This catalog does not claim that all listed tools are installed or tested.
