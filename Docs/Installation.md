# Installation Guide

**Status:** Draft — hardware and Linux distribution not yet confirmed.

1. Record the HP Pavilion model, CPU architecture, RAM, storage, and network chipset in [Hardware.md](Hardware.md).
2. Back up any existing data before changing partitions or replacing the OS.
3. Boot a Linux Mint XFCE or Debian XFCE live USB and verify display, keyboard, Wi-Fi, Ethernet, USB and storage.
4. Select the distribution after confirming compatibility.
5. Review [../Setup/Packages.txt](../Setup/Packages.txt) and [../Setup/Install.sh](../Setup/Install.sh) before installing software.
6. Validate disk diagnostics, serial communication, network packet capture and a safe Modbus test on noncritical hardware.

**Safety:** Never automatically wipe drives, flash devices, or actuate industrial I/O. Confirm target identity and electrical compatibility first.
